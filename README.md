## Функциялар

- Пайдаланушыны тіркеу;
- Авторизация;
- Logout;
- Парольдерді хеш түрінде сақтау;
- SQLite деректер базасы;
- Авторизацияланған пайдаланушыға сабақ кестесін көрсету;
- HTML және CSS арқылы безендіру.

## Іске қосу

Виртуалды ортаны жасау:

```bash
python -m venv venv
```

Windows-та іске қосу:

```bash
venv\Scripts\activate
```

Кітапханаларды орнату:

```bash
pip install -r requirements.txt
```

Деректер базасын жасау:

```bash
python database.py
```

Қосымшаны іске қосу:

```bash
python app.py
```

Браузерде ашу:

```text
http://127.0.0.1:5000
```
